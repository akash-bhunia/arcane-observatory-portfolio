# Arcane Observatory — 3D Interactive Developer Portfolio

An interactive 3D developer portfolio built with **Next.js (App Router)**, **React Three Fiber**, **Framer Motion**, **Tailwind CSS**, and **MongoDB**, featuring an observatory-themed UI, project showcase, about and certificates pages, contact workflow, and portfolio management (`/edit`).

## Features

- **3D Interactive Scene:** Built with React Three Fiber and Three.js with smooth motion via Framer Motion.
- **Multi-Page App Router Structure:** Dedicated routes for Home (`/`), About (`/about`), Projects (`/projects`), Certificates (`/certificates`), Contact (`/contact`), and Editor (`/edit`).
- **Backend API & Database:** Dynamic portfolio data route (`/api/portfolio`) backed by MongoDB.
- **Responsive UI:** Styled with Tailwind CSS for desktop and mobile viewports.

## Tech Stack

- **Framework:** Next.js 14 (App Router)
- **3D & Animation:** Three.js, React Three Fiber, Framer Motion
- **Styling:** Tailwind CSS
- **Database:** MongoDB
- **Deployment:** Render
